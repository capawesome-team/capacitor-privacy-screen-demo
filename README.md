# Capacitor Privacy Screen Plugin Demo App

⚡️ Simple vanilla JS + Capacitor app to demonstrate the use of the [Capacitor Privacy Screen plugin](https://capawesome.io/docs/sdks/capacitor/privacy-screen/).

📖 Read the accompanying blog post: [Capacitor Privacy Screen: Hide Sensitive App Content](https://capawesome.io/blog/capacitor-privacy-screen-hide-app-content).

## Plugins

The following plugins are included:

- [capawesome-team/capacitor-privacy-screen](https://capawesome.io/docs/sdks/capacitor/privacy-screen/)

## Development 💻

### Prerequisites

- Install [Node.js](https://nodejs.org) which includes Node Package Manager
- Android development: Install [Android Studio](https://developer.android.com/studio)
- iOS development: Install [Xcode](https://apps.apple.com/de/app/xcode/id497799835?mt=12)

### Getting Started

```bash
# Clone this repository
$ git clone https://github.com/capawesome-team/capacitor-privacy-screen-demo.git

# Change to the root directory of the project
$ cd capacitor-privacy-screen-demo

# Install all dependencies
$ npm i

# Run the web app
$ npm run dev

# Build the web app
$ npm run build

# Run the Android app
$ npx cap sync android
$ npx cap run android

# Run the iOS app
$ npx cap sync ios
$ npx cap run ios
```

This project uses plain [Vite](https://vite.dev/) and vanilla JavaScript, without any UI framework.
